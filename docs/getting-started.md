# Getting Started

Welcome to Vapor3D.

## Requirements

- TurboWarp
- WebGL2 compatible browser

## Installation

1. Download the latest version from [GitHub Releases](https://github.com/JoyFul721/Vapor3D/releases).
2. Download `vapor3d.js` from the release assets.
3. Open [TurboWarp](https://turbowarp.org/).
4. Load the extension using the custom extension loader.
